# Installing GQR 0.1.0

GQR is distributed here as an R package source directory. If it is supplied in
a ZIP file, extract the ZIP into a new empty directory before installation.

## Install the extracted source

```r
install.packages("devtools")

pkg <- "D:/path/to/GQR"
devtools::install(pkg, upgrade = "never")
```

## Full development workflow

```r
pkg <- "D:/path/to/GQR"

devtools::document(pkg)
devtools::test(pkg)
devtools::check(pkg)
devtools::install(pkg, upgrade = "never")
```

All manual pages are generated by roxygen2 from comments in `R/`. Do not edit
files under `man/` directly.

## Build a standard source archive

```r
archive <- devtools::build(pkg)
install.packages(archive, repos = NULL, type = "source")
```

## Verify the installation

```r
library(GQR)
packageVersion("GQR")
help(package = "GQR")
?gqr_methodology
```

## Load the example datasets

```r
data("dummy_data", package = "GQR")
data("gardening", package = "GQR")

dummy <- gqr_example_data("dummy_data")
garden <- gqr_example_data("gardening")
```

## Start the graphical interface

```r
run_gqr()
```

If graphical dependencies are missing, `run_gqr()` lists the packages that
must be installed.
