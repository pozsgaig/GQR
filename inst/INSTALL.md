# Installing GQR

## Install the current development version from GitHub

```r
install.packages("remotes")

remotes::install_github(
  "pozsgaig/GQR",
  dependencies = TRUE,
  upgrade = "never"
)
```

Load and verify the installation:

```r
library(GQR)
packageVersion("GQR")
help(package = "GQR")
```

## Install a local development copy

Clone the repository:

```bash
git clone https://github.com/pozsgaig/GQR.git
```

Open the cloned package in RStudio or set the working directory to the package root, then run:

```r
devtools::document()
devtools::test()
devtools::check()
devtools::install(upgrade = "never")
```

All manual pages are generated by roxygen2 from comments in `R/`. Do not edit files under `man/` directly.

## Load the example datasets

```r
data("dummy_data", package = "GQR")
data("gardening", package = "GQR")

# Direct-return alternative
dummy <- gqr_example_data("dummy_data")
garden <- gqr_example_data("gardening")
```

## Start the graphical interface

```r
run_gqr()
```

If graphical dependencies are missing, `run_gqr()` reports the packages that must be installed.
